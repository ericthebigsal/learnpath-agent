# Amperity pilot content

Output of the platform-pivot pilot described in `docs/platform-pilot-plan.md`
(run 2026-08-06). Not the learnpath-agent app's own catalog — a separate,
same-schema catalog generated for a bounded 4-track / 14-course slice of
docs.amperity.com, to test whether the content pipeline generalizes past the
AI/agentic domain.

- `amperity-pilot-catalog.json` — the 14 courses (`CourseItem`-shaped, same
  schema as `data/catalog.json`), reusable as-is if this ever becomes a live
  demo instance.
- Full taxonomy proposal (9 tracks / 27 courses, of which this slice is 4/14):
  https://claude.ai/code/artifact/cea04968-894c-4262-a5d7-71073db5ddc4
- Browsable pilot content review (read every section + quiz):
  https://claude.ai/code/artifact/f5580b7a-9d33-425a-b77e-1f19e5dc1fdf

See the Pilot Log and Decision gate in `docs/platform-pilot-plan.md` for the
review verdict and its caveats.
